---
name: Static site editing
description: Editing guidance for the dependency-free THE WORKOUTS static site.
---

Targeted edits are safer after reformatting or isolating long single-line HTML sections; exact-line patches are brittle when several similar footer or CTA variants exist.

**Why:** Repeated patch attempts were needed because each page keeps large sections on single lines with small page-specific differences.

**How to apply:** Search first, patch one page-specific section at a time, then run a cross-page link and placeholder audit.
